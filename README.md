# 🎬 JuzzWatch – Cine-Stream

A modern movie discovery application built with **Next.js 15**, **React**, and the **TMDB API**.

## ✨ Features

- 🎥 Browse popular movies
- 🔍 Search movies
- ♾️ Infinite scrolling
- ❤️ Add/remove favorite movies
- 🎬 Global favorites state with **Redux Toolkit**
- 🔎 Advanced filters — Genre, Rating & Release Year
- ⚡ Optimized filtering with `useMemo`
- 🚀 Optimized callbacks with `useCallback`
- 🌙 Global Dark/Light theme
- ✨ AI Mood Matcher powered by Gemini
- 📄 Dynamic movie details pages
- 🔎 SEO-optimized metadata
- ⚡ Server-side data fetching
- 📱 Responsive UI

## 🛠️ Tech Stack

**Next.js 15 • React • JavaScript • Redux Toolkit • TMDB API • Gemini AI • CSS**
