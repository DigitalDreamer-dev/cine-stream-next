# 🎬 JuzzWatch – Cine-Stream

A movie discovery application built with **Next.js 15** and the **TMDB API**.

live website Link: https://cine-stream-next-six.vercel.app/

### ✨ Features
- 🎥 Browse popular movies
- 🔍 Search movies
- ♾️ Infinite scrolling
- ❤️ Save favorite movies
- ✨ AI Mood Matcher
- 📄 Dynamic movie details
- 🔎 SEO-optimized metadata
- ⚡ Server-side data fetching

### 🛠️ Tech Stack
**Next.js 15 • React • JavaScript • TMDB API • Gemini AI • CSS**

### 🚀 Run Locally

```bash
npm install
npm run dev
